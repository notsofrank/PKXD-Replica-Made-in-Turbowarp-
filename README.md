# Mini-XD
A 3D multiplayer replica of PK XD built in TurboWarp using the Simple 3D extension.

### Play Online
[**Play Mini-XD in your browser**][(https://github.io)](https://notsofrank.github.io/PKXD-Replica-Made-in-Turbowarp-/)

### Controls
- **WASD / Arrow Keys:** Walk & turn
- **Space:** Jump

### Features
- **5-Player Live Multiplayer:** Real-time cloud sync with automatic Tiny House plot claiming (`1`–`5`) and floating 3D roof markers.
- **Randomized Outfits:** Spawn as an Astronaut, Neon Armor, or News Guy.
